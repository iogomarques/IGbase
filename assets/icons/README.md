# ig-base-icons

9 icons in the **ig-line-fill** style, drawn on a 24 px grid with a 20 px live area.
Generated by the `generate-icons` skill from `icons.json`. Do not edit the generated files by hand:
change the source and run the build again.

## Use

```html
<!-- inline sprite (inherits CSS variables) -->
<svg width="24" height="24" aria-hidden="true"><use href="/sprite.svg#fatura"/></svg>
<!-- standalone file (hex colors, works in <img>, e-mail and design tools) -->
<img src="/svg/fatura.svg" width="24" height="24" alt="Fatura (Solar Organization)">
```

- `size` sets width and height (default 24).
- Without `title` or `aria-label` the icon is decorative and gets `aria-hidden`.
  With either one it becomes `role="img"` with an accessible name. Use that when the icon is the only
  thing that carries the meaning (an icon-only button still needs its own `aria-label` on the button).
- Each icon is its own module, so bundlers keep only the ones you import.

## Colors and states

Every shape is painted with a CSS variable per tone (`--igi-line`, `--igi-body`), falling back to `currentColor`, so the icons work with no setup. Import `icons.css` once to get the exact palette, states and dark mode:

```css
@import "ig-base-icons/icons.css";
```

States follow the markup: `:hover` on links and buttons, `aria-current="page"`, `aria-selected`, `aria-pressed` and `data-icon-state="active"` for active, `:disabled`, `aria-disabled` and `data-icon-state="disabled"` for disabled. Dark mode follows `.igi-tema-escuro`. To recolor one place, set the variables there:

```css
.on-brand { --igi-line: currentColor; --igi-body: currentColor; }
```

## Files

| Path | What it is |
|------|------------|
| `src/` | One component per icon plus an index (absent for plain SVG). |
| `svg/` | Standalone SVGs with the default light palette in hex: for `<img>`, e-mail, Figma. |
| `sprite.svg` | All icons as `<symbol>`, painted with the CSS variables. |
| `icons.css` | The tone variables per state and theme. |
| `manifest.json` | Names, labels, groups and tags, for search or docs. |
| `catalog.html` | Review page: every icon in every state and size, light and dark. |
